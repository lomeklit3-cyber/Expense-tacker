## ✨ Features

- ⚡ **Real-Time Expense Logging:** Track income and expenses with customizable categories.
- 📊 **Visual Analytics:** Interactive charts providing deep insights into monthly spending trends.
- 🔔 **Smart Budgeting Alerts:** Set limits for expense categories and get notified before overspending.
- 📁 **Data Export:** Export transaction history anytime in CSV or PDF formats.
- 🌙 **Dark & Light Mode:** Sleek, responsive UI tailored for mobile, tablet, and desktop viewports.
